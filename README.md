# Leifeng Chen · Design Portfolio

Static site for GitHub Pages: a chat-first home (`index.html`), a grid view (`work.html`), and four case studies (`uncoded-resolve.html`, `eezy-receipt.html`, `hedron.html`, `warden-creations.html`). No build step for the pages themselves.

- Styles: `assets/style.css` (light and dark via `prefers-color-scheme`)
- Images: `assets/img/<project>/`, WebP, generated by `tools/build_images.py` from the original project folders (the `tools/` folder is local only and is gitignored)

Preview locally:

```
python -m http.server 8765
```

Publish: push to a public repo named `Redstoneweewee.github.io`, then Settings → Pages → Deploy from branch `main` / root.

## Ask me (the chat)

Every answer lives in `assets/answers.txt` as `"Question"="Answer"`, written by hand (the notes at the top of the file explain paragraphs, bold, lists, and the special `[more]`, `[fallback]`, and `[fourth wall]` entries). `assets/agent.js` loads that file and matches a visitor's question to the closest answer. It runs entirely in the browser: no API, no key, nothing sent anywhere, and after enough questions it says so itself.

To add a topic, add a line to `answers.txt`; it's matched on the question's own words. For better matching, case-study cards, pictures, or links, add an entry under the same question in `META` in `agent.js`.
